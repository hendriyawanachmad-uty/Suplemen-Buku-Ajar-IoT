# Bank Soal (Tambahan)

Folder ini menampung bank soal tambahan di luar self-assessment representatif yang tercetak di buku.
Tujuannya menekan jumlah halaman buku sekaligus memberi latihan lebih banyak bagi mahasiswa.

## Struktur yang disarankan
- Satu berkas per bab, mis. `bab-01.md`, `bab-02.md`, dst.
- Tiap berkas berisi: soal pilihan ganda, soal esai, dan kunci/rubrik di bagian akhir.
- Boleh disertai varian soal untuk kuis/ujian.

## Format soal (contoh)
```
1. [Pertanyaan]
   a. ...
   b. ...
   c. ...
   d. ...
   Kunci: c

Esai:
1. [Pertanyaan esai]
   Rubrik: [kriteria penilaian ringkas]
```

> Isi bank soal dilengkapi pada tahap penulisan tiap bab.
