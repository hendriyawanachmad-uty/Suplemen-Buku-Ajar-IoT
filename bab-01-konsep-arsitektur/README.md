# Bab 1 - Konsep dan Arsitektur IoT

- **Bab pada buku:** 1
- **Minggu (RPS):** 1-2
- **CPMK:** CPMK1

Bab ini bersifat konseptual dan tidak memerlukan perangkat keras maupun kode program,
sehingga folder ini hanya berisi materi latihan dan kunci jawaban.

## Isi folder
- `latihan/lembar-kerja-pemetaan.md` - lembar kerja untuk praktik mandiri (pemetaan sistem IoT).
- `latihan/contoh-pengerjaan.md` - contoh pengerjaan sebagai acuan.
- `kunci-jawaban-bab-01.md` - kunci pilihan ganda dan jawaban lengkap esai self-assessment.

## Praktik mandiri
Pilih satu sistem IoT nyata, lalu petakan komponennya ke ekosistem dan arsitektur berlapis
(tiga dan lima lapis), serta jelaskan aliran datanya. Gunakan lembar kerja pada folder `latihan/`
dan templat laporan pada [`../templat/laporan-praktik.md`](../templat/laporan-praktik.md).
