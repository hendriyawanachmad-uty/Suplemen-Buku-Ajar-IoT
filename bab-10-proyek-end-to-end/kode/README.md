# Kode Proyek Akhir

Folder ini menampung contoh proyek IoT end-to-end sebagai acuan, sekaligus tempat
mahasiswa menaruh kode proyeknya (mis. subfolder per kelompok).

Struktur disarankan:
- `contoh-irigasi-pintar/` - proyek contoh lengkap (sensor -> ESP32 -> cloud -> dashboard)
- `kelompok-XX/` - kode proyek mahasiswa

> Contoh proyek dilengkapi pada tahap penulisan Bab 10.
