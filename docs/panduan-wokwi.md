# Panduan Praktik dengan Wokwi (Tanpa Hardware)

Wokwi memungkinkan praktik ESP32 tanpa perangkat keras fisik.

1. Buka simulator Wokwi (peramban) atau pasang ekstensi Wokwi di VS Code.
2. Buat proyek ESP32 baru.
3. Salin kode dari folder `kode/` bab terkait.
4. Susun komponen sesuai berkas `diagram.json` pada folder `rangkaian/` bab tersebut.
5. Jalankan simulasi dan amati Serial Monitor.

> Setiap bab yang berbasis hardware akan menyediakan berkas `rangkaian/diagram.json`
> agar rangkaian dapat langsung dimuat di Wokwi.
